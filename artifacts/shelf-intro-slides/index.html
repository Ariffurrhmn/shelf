Shelf

A personal shelf for small HTML apps, tools and presentations.

Press → or space to continue, F for fullscreen.

The problem

  • I make small things with AI tools, one HTML file each.
  • They end up in downloads folders and chat histories.
  • A few weeks later I cannot find them, or reach them from another machine.

How it works

  1. A spec says what an artifact must look like.
  2. A paste-in prompt makes any AI session follow it.
  3. A validator checks the result and scans for secrets.
  4. A build creates thumbnails and a gallery.
  5. A push deploys it as static pages.

What it is not

  • Not a platform: one person, no accounts.
  • Not a service: static files, no database.
  • Not private: the repo and site are public.

The use case

A room machine I have never used. No sign-in, no drive. I open one address, tap the deck and press F.

The same link works from my phone if the room machine fails.
